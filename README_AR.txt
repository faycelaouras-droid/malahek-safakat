تطبيق ملاحق الصفقات العمومية — مشروع أندرويد تجريبي

أضفنا شاشة بداية تحمل الاسم «المهندس فيصل أوراس» فقط، وأضفنا إعدادًا لبناء APK عبر GitHub Actions. لم يُنشأ ملف APK داخل هذه الحزمة بعد.

طريقة الحصول على APK دون حاسوب (تحتاج حساب GitHub ومتصفح الهاتف):
1) أنشئ مستودعًا جديدًا على GitHub من المتصفح.
2) ارفع ملفات هذا المجلد إلى المستودع مع الحفاظ على المجلدات، ومنها .github/workflows/build-apk.yml.
3) افتح تبويب Actions، واختر Build Android APK، ثم Run workflow.
4) بعد نجاح البناء، افتح تشغيل workflow وانزل إلى Artifacts، ثم نزّل mala7iq-safa9at-debug-apk.zip.
5) فك ضغط الملف على الهاتف وثبّت app-debug.apk. قد يطلب أندرويد السماح بالتثبيت من هذا المصدر. لا تشارك ملف APK من مصدر غير موثوق.

ملاحظات مهمة:
- هذه نسخة تجريبية غير مختبرة على جميع الهواتف وليست منتجًا رسميًا نهائيًا.
- قراءة Excel تعتمد على مكتبة SheetJS عبر الإنترنت.
- لا يتضمن التطبيق بعد OCR فعليًا لصور الحوصلة.
- راجع كل الحسابات والبيانات قبل اعتماد أي ملحق رسمي.
- APK الناتج من هذا الإجراء هو debug APK للتجربة، وليس إصدارًا متجرّيًا موقّعًا للنشر.
